# 3.0.0 变更与来源

GUI 的界面流程沿用 SeaLoong 原始实现，保留多账号、指定网卡/IP、托盘及自动认证。

参考 [LuoMuQAQ/drcom4scut](https://github.com/LuoMuQAQ/drcom4scut) 所体现的便捷使用需求，本轮重新实现按用户选择的 Windows 登录启动和连接状态呈现；未复制第三方二进制或计划任务实现。启动项使用当前用户 HKCU Run，无需提权。认证成功从单独的 802.1X 成功调整为 UDP 心跳完成（或用户明确启用的仅 EAP 模式），与核心异步状态一致。

安全设计、异步进程管理、DPAPI 迁移、脱敏诊断和测试使用本仓库新实现。跨平台测试不能代替真实 Windows UI、Npcap 驱动和校园网验证。

本轮还增加无线 Portal 图形配置（明确指定可信门户/API、独立的源 IP 和协议载荷 IP、显式 HTTP 风险选择），以及随机私有管道的优雅注销/父进程断开退出。模式选择始终显式覆盖旧核心配置，不以旧 `core.yml` 决定远端凭据提供者。
