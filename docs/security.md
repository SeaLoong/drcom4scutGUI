# 账号、密码与诊断

[返回首页](../README.md)

你可以选择让程序记住密码，也可以每次重新输入。排障时可以分享诊断文本，但不要直接上传账号配置。本页说明保存了什么、换电脑时该怎么办，以及哪些信息不应公开。

## 记住密码意味着什么

勾选“记住密码”后，程序借助当前系统用户的密码保护功能保存密码。Windows 使用系统自带的保护，Mac 使用登录钥匙串，Linux 使用桌面密码库。取消勾选则不保存密码，本次认证仍可使用刚输入的内容。

因此，别人拿到一份配置文件，不等于能够直接在另一台电脑上恢复密码；你也不应把它当作密码备份。换电脑、换系统用户或丢失系统密码库后，应准备重新输入密码。

Linux 需要可用且已解锁的桌面密码库，以及提供 `/usr/bin/secret-tool` 的工具包。缺少条件、密码库被锁定或拒绝访问时，程序会报告问题，**不会为了保存成功而改写成明文**。暂时无法解决时，取消“记住密码”并重新输入密码即可尝试本次认证。安装说明见 [Linux 使用](usage.md#linux)。

这项保护不能阻止已经控制你当前系统账号的恶意程序，也不保证运行时内存中没有密码。请仍然保护好电脑登录账号。

## 保存了哪些内容

配置保存在当前系统用户的目录，不在 GUI 安装文件夹中：

| 系统 | 配置文件 `config.json` 的位置 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\drcom4scutGUI\config.json` |
| macOS | `~/Library/Application Support/drcom4scutGUI/config.json` |
| Linux | `$XDG_CONFIG_HOME/drcom4scutGUI/config.json`；该变量不是有效绝对路径时使用 `~/.config/drcom4scutGUI/config.json` |

| 信息 | 是否保存 |
| --- | --- |
| 勾选“记住密码”的密码 | 受系统用户保护后保存，不按原文写入 |
| 未勾选“记住密码”的密码 | 不保存，只留在当前运行中 |
| 账号、网卡地址、IP 地址 | 普通文本保存 |
| 登录网页地址、认证模式、自动选项 | 普通文本保存 |

**配置不是可以随便公开的文件。** 即使密码受保护，其他字段仍会透露账号和网络信息。密码也不会放进核心程序的启动参数或环境变量；用户名和地址则可能出现在本机配置或进程信息中。

需要核对实现时：Windows 使用 DPAPI CurrentUser；macOS 登录钥匙串、Linux Secret Service 保存加密密钥，密码本身以 AES-GCM 密文写入配置。密钥不会另存成配置旁的明文文件。接口细节见[开发说明](development.md#系统适配与秘密存储)。

## 更换或删除账号

先停止认证，再选择或输入账号。改好密码后点击“认证”；是否保存新密码由该账号的“记住密码”决定。删除账号时，选中后点击“删除”并确认。具体步骤见[多账号操作](usage.md#多账号)。

这只会改动电脑上的记录，不会修改或删除学校提供的账号。学校侧的密码请在学校账号管理入口修改。

如果提示配置无法读取或密码无法恢复，原文件会保留。重新输入并保存时，程序会用新的配置替换它；若需要保留其他账号记录，请先妥善保存原文件，再按提示处理。保存的副本也不应上传到公开问题区。

## 导出和分享诊断

连接失败时，点击“导出诊断”并选择保存位置。文件包含 GUI 和核心版本，以及窗口中保留的日志，能帮助判断在哪一步出错。较早日志会随着缓冲长度限制被移除，遇到问题后可及时导出。

分享前请完成以下检查：

1. 用文本编辑器打开导出的文件。
2. 检查账号、IP、网卡地址、电脑名称、登录页地址和学校返回的内容，删去不想公开的部分。
3. 仅分享排障需要的内容，附上系统、版本和操作经过。
4. 不要附 `config.json`、旧账号文件、密码文件、浏览器登录请求或私人网络抓包。

程序会隐藏已知密码和当前账号的对应文本，但自动隐藏不等于完整的隐私检查，仍需自己确认。

## 无线门户与密码传输

校园无线登录仍是“向学校网页提交账号密码”。**电脑上如何记住密码，与提交时网络是否加密，是两回事。**

`https://` 地址提供加密传输并检查服务器证书。`http://` 没有这层保护，账号密码可能被网络中的其他人读取。只有确认学校实际只提供 HTTP，并接受这一点时，才勾选“允许 HTTP 门户明文网络传输”。程序不会因为 HTTPS 失败就自动退回 HTTP。

登录页地址应来自学校实际使用的入口。不要将含密码、令牌或会话信息的网址粘贴到地址框。高级“API 地址”是网页提交给后台的地址，必须与入口使用同一主机，不能随意换到另一个网站。公开网络定位参数可以保留；不支持的参数会被拒绝。

无线自动登录只支持特定网页流程，尚未经实际校园网验证。浏览器能正常登录而程序不能时，可以继续使用浏览器，不需要为此关闭证书检查或把密码交给未知网站。适用范围见[无线说明](usage.md#无线-portal)。

## 高级：旧文件和账号恢复

以下只在你曾使用旧版程序、需要排查旧配置时有用。新安装的用户无需手工寻找这些文件。

新配置不存在时，GUI 会尝试读取安装目录的 `drcom4scutGUI.json`；若不存在，再尝试启动工作目录中的 `gui.json`。已有的新配置读取失败时，不会悄悄换用另一份旧文件。

只有旧文件中的所有密码都已保护、并成功写入新配置后，才删除旧源文件，不创建含明文密码的 `.bak`。转换或删除失败会报告并保留相应文件。请确认新配置可以使用，再处理留下的旧副本。

删除文件不代表系统备份、文件历史或磁盘旧数据已经擦除。以前保存过的明文备份仍需自行检查和清理，不要上传到问题反馈或代码仓库。

`core.yml` 存放额外的核心选项，不是 GUI 密码库。GUI 不会把本次密码写进去；若以前曾手工填写明文密码，请停止认证后自行移除，程序不会擅自删除你写入的内容。
