# 账号、密码与诊断

[返回首页](../README.md)

客户端支持按账号选择“记住密码”。需要排障时，可以导出诊断文本；本页说明密码保存方式、账号管理和分享方法。

## 记住密码意味着什么

勾选“记住密码”后，密码交由当前系统用户的保护机制保管：Windows 使用系统保护，Mac 使用登录钥匙串，Linux 使用桌面密码库。取消勾选则仅将本次输入用于当前连接。

换电脑、更换系统用户或重置密码库后，重新输入校园密码即可。日常请保护好电脑登录账号；校园密码本身仍在学校账号管理入口修改。

Linux 需要已解锁的桌面密码库和 `libsecret-tools` 提供的 `/usr/bin/secret-tool`。密码库暂时不可用时，可取消“记住密码”，填写密码后继续连接。详见 [Linux 安装](usage.md#linux)。

## 保存了哪些内容

配置保存在当前系统用户目录：

| 系统 | 配置文件位置 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\drcom4scutGUI\config.json` |
| macOS | `~/Library/Application Support/drcom4scutGUI/config.json` |
| Linux | `$XDG_CONFIG_HOME/drcom4scutGUI/config.json`；未设置有效绝对路径时为 `~/.config/drcom4scutGUI/config.json` |

| 内容 | 保存方式 |
| --- | --- |
| 勾选“记住密码”的密码 | 系统保护后的密文 |
| 未勾选“记住密码”的密码 | 仅用于本次运行 |
| 账号、网卡、IP、登录页地址 | 配置文件中的普通文本 |
| 连接方式、自动启动和连接选项 | 配置文件中的普通文本 |

配置包含个人账号和网络信息，适合保存在自己的设备上。排障时分享下文的诊断文本即可。

GUI 与核心之间通过私有输入通道传递密码；系统的进程参数和环境变量中不放密码。实现细节见[开发说明](development.md#系统适配与秘密存储)。

## 更换或删除账号

先断开连接，再选择或输入账号。填写新密码后，按需勾选“记住密码”并点击“连接”。删除本机记录时，选中账号后点击“删除”并确认。操作步骤见[多账号](usage.md#多账号)。

配置无法读取或密码无法恢复时，原文件会保留，便于找回其他账号信息。重新输入并保存会写入新配置；需要保留原记录时，可先自行备份到私人目录。

## 导出和分享诊断

点击“导出诊断”，选择保存位置。文本包含 GUI、核心版本和窗口日志，适合判断连接卡在哪一步。遇到问题后及时导出，能保留更多上下文。

分享时：

1. 用文本编辑器打开导出的文件，确认内容。
2. 将账号、IP、网卡地址、电脑名称等私人信息替换成说明文字，例如 `[本机 IP]`。
3. 附上操作系统、程序版本、校区和发生问题前后的操作。

程序会在日志进入缓冲区前隐藏已知密码和账号文本；学校返回的其他信息由你在分享前确认。公开求助使用这份处理后的文本，账号配置、密码文件与浏览器登录请求留在本机。

## 无线门户与密码传输

校园网页认证会向学校登录入口提交账号密码。`https://` 通过证书检查并加密传输，是优先选择。

学校只提供 `http://` 时，可核对入口后勾选“登录页使用 HTTP（明文传输）”。HTTP 会在网络中明文发送账号密码；本机密码库保护的是保存的密码，传输保护取决于学校提供的协议。

“登录页地址”填写学校公开的登录入口，即尚未提交账号密码时的页面地址。“API 地址”通常留空；手动填写时，使用同一主机的后台地址，并保持 HTTPS 入口的加密方式。

支持的网页流程和使用步骤见[校园网页认证](usage.md#无线-portal)。

## 高级：旧文件和账号恢复

新配置不存在时，GUI 会尝试读取安装目录的 `drcom4scutGUI.json`，其次是启动目录的 `gui.json`。已有配置读取失败时，保留原文件以便处理。

旧文件的全部密码成功保护并写入新配置后，程序会删除旧源文件；转换或删除失败会给出提示并保留文件。确认新配置可以使用后，可自行清理留下的旧副本及备份。

`core.yml` 用于额外核心选项，GUI 从窗口提供登录密码。以前手动写入其中的密码，可在断开连接后移除。
