# 账号、密码与诊断

[返回首页](../README.md)

## 保存了哪些内容

GUI 配置位于 `%LOCALAPPDATA%\drcom4scutGUI\config.json`。

| 内容 | 保存方式 |
| --- | --- |
| 密码 | 使用 Windows 当前用户的 DPAPI 保护后保存 |
| 用户名、网卡 MAC、IP | 普通配置文本，不加密 |
| 门户地址、认证模式、自动认证等选项 | 普通配置文本，不加密 |

因此，配置文件不应作为公开附件分享。密码不会放入核心进程的命令行参数或环境变量；用户名和所选地址仍可能出现在本机配置或进程信息中。

密码保护与当前 Windows 用户关联。它不保护已经控制此用户会话的程序，也不保证进程内存中不存在密码。更换电脑或 Windows 用户时，应准备重新输入密码，不要把配置文件当作可移植的密码备份。

## 更换或删除账号

先停止认证，再在界面选择或输入账号。修改密码后点击“认证”保存并使用新密码；删除已保存账号时，选中它并点击“删除”。详细操作见[多账号](usage.md#多账号)。

删除本机记录不会改变校园账号本身。要修改学校侧密码，请使用学校提供的账号管理入口。

如果出现无法读取或解密配置的提示，原文件会保留。重新输入账号并认证时，GUI 会用新的配置替换它；需要保留其他记录时，应先妥善保存原文件，再按提示处理。

## 导出和分享诊断

点击“导出诊断”后选择保存位置。文件包含 GUI/核心版本及保留的日志文本，便于判断网卡、认证阶段和重试情况。

GUI 会隐藏已知密码和当前账号的对应文本，但这不等于完整的隐私检查。发送前应打开文件，确认没有不愿公开的账号、IP、MAC、主机名、门户地址或服务器返回内容。不要同时上传 `config.json`、含凭据的旧配置或自己的密码文件。

日志缓冲有长度上限，长时间运行后较早的内容会被移除；出现问题后可以及时导出。

## 无线门户与密码传输

本机密码保存方式与到校园门户的网络传输是两件事。

默认使用 HTTPS，不会自动降级为 HTTP。只有在确认校园门户必须使用 HTTP，并接受账号密码在网络中明文传输的风险后，才勾选允许 HTTP。将密码保存在受保护的本机配置中，并不能让 HTTP 连接变成加密连接。

门户和 API 必须使用可信地址，API 不能更换为另一主机。不要把密码、令牌或会话信息粘贴进 URL；程序只接受公开接入点发现字段组成的查询参数。

## 高级：旧文件和账号恢复

新配置不存在时，GUI 会尝试读取安装目录的 `drcom4scutGUI.json`；若该文件不存在，再尝试启动工作目录中的 `gui.json`。已有的新配置读取失败时，不会悄悄改用另一份旧文件。

旧文件中的密码全部保护并成功写入新配置后，才会删除旧源文件，不创建含明文密码的 `.bak`。转换或删除失败会报告问题并保留相应文件；应确认新配置可用后，再处理仍保留的旧副本。

文件被删除不代表系统备份、文件历史或磁盘上的旧数据已被擦除。已有的明文备份需要自行检查和清理，不要上传到问题反馈或代码仓库。

`core.yml` 是核心选项文件，不是 GUI 的密码库。GUI 不会把本次密码写入其中；若曾手工在该文件填入明文密码，应停止认证后自行移除。GUI 不会擅自清理用户手工添加的内容。
